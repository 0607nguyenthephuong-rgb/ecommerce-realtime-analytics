# Data dictionary and event contract

The source has nine columns. These descriptions are adapted from the [publisher's data card](https://www.kaggle.com/datasets/mkechinov/ecommerce-events-history-in-cosmetics-shop).

| Source column | Meaning | Starter JSON representation |
| --- | --- | --- |
| `event_time` | Event timestamp in UTC | ISO 8601 UTC string |
| `event_type` | User action | `view`, `cart`, `remove_from_cart`, or `purchase` |
| `product_id` | Product identifier | Digit string |
| `category_id` | Category identifier | Digit string or null |
| `category_code` | Category taxonomy | String or null |
| `brand` | Brand name | String or null |
| `price` | Product price | Decimal string |
| `user_id` | User identifier | Digit string |
| `user_session` | Session identifier | String or null |

Representation and validation rules below are project design choices. Identifiers remain strings to avoid loss of precision in JavaScript clients. Prices remain decimal strings; Spark should cast them to an agreed decimal type before aggregation. The starter does not infer currency.

## Added fields

| Field | Project rule |
| --- | --- |
| `schema_version` | Event contract version, initially `1.0` |
| `dataset_version` | Caller-supplied immutable snapshot label |
| `source_file` | Original CSV basename |
| `source_row_number` | One-based data-record index, excluding the header |
| `event_id` | SHA-256 of snapshot label, basename, row index, and ordered raw field values |
| `emitted_at` | UTC replay emission timestamp |
| `quality_flags` | Array, currently empty or containing `negative_price` |

`event_id` is generated by the project; it is not a native source identifier. It identifies replay of the same source record, not business-level uniqueness. Moving a file without changing its basename preserves identity; changing its basename, row position, snapshot label, or raw values changes identity. Do not use the same basename for different files in one snapshot.

## Validation policy

- Require the exact nine source column names; reject duplicate, missing, or unexpected headers.
- Fail the starter replay on invalid timestamps, missing product/user identifiers, unsupported actions, or non-finite prices.
- Preserve missing category, brand, category code, and session values as null.
- Preserve zero prices. Flag negative prices and exclude them from the proposed purchase-value metric until their meaning is established.
- Do not manufacture session IDs for missing sessions. Exclude those events from session metrics and report the exclusion count.

The machine-readable output contract is [event.schema.json](../schemas/event.schema.json). Production quarantine handling is assigned to Quyền; the starter stops on invalid records instead of silently dropping them.
